# Conny — Professional Networking

[← Portfolio](../README.md)

## The problem

Professional events can make it difficult to meet people comfortably. A networking product also needs clear consent and tools for people to control unwanted interactions.

## My work

I built an application with a Fastify and PostgreSQL backend and an Expo/React Native mobile interface. Its core workflow includes event rooms, gatherings, mutual interest, consent-gated contact, blocking, and reporting.

```text
Join a gathering
       ↓
Mutual interest and consent
       ↓
Communication

Blocking can restrict interactions across the experience.
```

## Skills demonstrated

TypeScript · Fastify · PostgreSQL · React Native / Expo · authentication · consent and safety workflows
