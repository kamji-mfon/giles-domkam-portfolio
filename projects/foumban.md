# Foumban — Architecture and Design Thinking

[← Portfolio](../README.md)

## The idea

I explore how principles from African architecture can inform the way cloud systems are described and designed. The work uses diagrams and explicit mappings between a source concept and a technical design idea.

## My work

The project includes diagram templates, structured mappings, and reference scaffolding for selected infrastructure patterns. The mappings identify the kind and strength of an analogy and include a way to question it.

## Skills demonstrated

Systems thinking · cloud architecture · diagrams · research interpretation · technical documentation

## Boundaries

An analogy is a design aid, not proof of a historical or technical equivalence. Reference scaffolding and conceptual diagrams should not be read as a claim that every pattern is deployed or independently validated.

**Project status:** architecture exploration and reference scaffolding; selected public description.
