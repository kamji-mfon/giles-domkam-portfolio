# Contributing and evidence review

This is currently a portfolio maintained by its owner. A contribution guide does not imply an independent reviewer or a multi-person team.

Proposed changes should identify the claim being changed, the source or runnable check supporting it, and its limitations. Use synthetic or explicitly approved data; do not submit credentials, customer files, licensed standards text, or private implementation. Review third-party rights before including material.

Run the checks in [the review process](technical/review-process.md). Public examples are illustrations and must not be described as production controls or physical validation. The owner must review any material proposed for publication. No license is included; contact the owner about reuse or contribution terms before submitting code for incorporation.
